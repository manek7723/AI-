# Madhvi Enterprise Company Profile Website

## Open the project
1. Download or clone this repository.
2. Open the folder.
3. Double-click `index.html` (or right-click and open in any browser).

No build step is required.

## Edit the text
- Main profile content is inside `index.html`.
- Update section text directly in the matching section blocks.
- Visual style settings (colors, spacing, typography) are in `styles.css`.
- Scroll reveal behavior is in `script.js`.

## Export to PDF
1. Open `index.html` in your browser.
2. Press `Ctrl+P` (Windows/Linux) or `Cmd+P` (Mac).
3. Choose **Save as PDF**.
4. Keep default margins or set minimal margins for a booklet-style result.
5. Save.

Print-specific styling is already included in `styles.css` for clean page breaks.
